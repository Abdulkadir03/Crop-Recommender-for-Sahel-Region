# data/

Small reference files only. Raw and intermediate data are not stored in this repository.

| File | Description | Source |
|---|---|---|
| `states.geojson` | Simplified state and province boundaries for the nine study countries (columns `adm0`, `adm1`, `adm1_code`) | Derived from FAO GAUL 2015 level 1, simplified to about 1 km. [CONFIRM: GAUL terms of use] |
| `training_config.json` | Feature list, feature groups, crop list and fold settings used for modelling | Produced by notebook 07 |

Everything else (parquet files and raw downloads) lives in Google Drive and is regenerated by the notebooks. See `docs/data_sources.md` for how to obtain the raw data.
